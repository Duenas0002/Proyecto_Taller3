# Proyecto Taller 3 — Sistema de Gestión de Préstamos

Proyecto universitario desarrollado en Java para la gestión de préstamos con interfaz gráfica y persistencia local en archivo.

> **Nota:** Copia y resubida organizada del repositorio inicial.

## Estructura del proyecto

* **Estructura en diseño por capas:** La separación del proyecto permite que funcione de manera mas organizada y sea escalable con mas facilidad

## Notas importantes

* **Persistencia de datos:** al ejecutarse y guardar información, el programa genera o actualiza el archivo "prestamos.dat" con los registros ingresados.
* **Persistencia de datos MEJORADA:** La copia de seguridad de la información ingresada en el programa es generada o actualizda en el archivo "prestamos.dat.bak"
